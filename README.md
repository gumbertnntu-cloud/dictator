# Dictator

Dictator is a small macOS menu bar utility for local, offline Russian-language
dictation powered by GigaAM v3 e2e RNNT.

## Status

This is the v1 release-candidate. Apple Silicon is the supported architecture.

- macOS 13+ SwiftUI menu bar app (`LSUIElement`, no Dock icon).
- Settings window: model state, hotkey, press mode, Save.
- Press modes: hold-to-talk and toggle.
- Microphone capture via `AVAudioEngine`, no transcript logging, no history.
- Compact status bubble that anchors **next to the active text caret** via
  Accessibility queries (with a top-of-screen fallback for apps that don't
  expose caret bounds).
- Animated bubble states:
  - **Listening** — translucent capsule with a live audio waveform.
  - **Transcribing** — translucent circle with a softly shimmering rainbow
    `sparkles` glyph and three rotating particles.
  - **Inserted** — no bubble (the inserted text is itself the confirmation).
  - **Fallback** — small bubble with a `Copy` button when direct AX insertion
    is not available.
  - **Error** — short message inside the bubble.
- Insertion strategy with three layers:
  1. Menu-bar `Paste` / `Вставить` via Accessibility.
  2. Global `Cmd+V` via `CGEvent`.
  3. Per-PID `Cmd+V` via `CGEvent.postToPid`.
- Pasteboard is snapshotted before insertion and restored ~450 ms after, so
  the user's clipboard contents are not clobbered.
- Long recordings (> 25 s) are chunked into 20-second segments transcribed
  sequentially.
- Per-chunk hard timeout (120 s) and cooperative cancel that propagates into
  `Process.terminate()` if the runtime hangs.
- Empty transcripts (no speech, sub-150 ms recordings) insert a single `-`
  placeholder instead of an error message.
- Custom purple/pink microphone icon generated by `script/make_icon.swift`.

## Run locally

```bash
./script/build_and_run.sh
```

## ASR runtime

The app shells out to one of three local GigaAM backends, resolved once per
session and cached:

1. `gigaam-mlx` — fastest path on Apple Silicon (recommended).
2. `gigastt`.
3. `python3` with the `gigaam` module installed.

From the packaged app's Settings window you can press **Prepare Dictator**.
It installs `uv` into the app's Application Support directory, installs
`gigaam-mlx`, and prewarms the GigaAM model cache. No Homebrew or Terminal
step is required on Apple Silicon.

For local development you can install a backend yourself:

```bash
uv tool install git+https://github.com/aystream/gigaam-mlx.git
```

Intel packaging still needs separate backend validation.

## Custom icon

The microphone icon is regenerable:

```bash
./script/make_icon.sh
```

This regenerates `assets/AppIcon-1024.png`, `assets/AppIcon.iconset/`, and
`assets/AppIcon.icns`. `script/package_app.sh` copies the `.icns` into the
bundle and adds `CFBundleIconFile` to `Info.plist` automatically.

Edit constants in `script/make_icon.swift` to change the design.

## Bundled-runtime packaging (optional)

`script/package_app.sh` and `script/package_dmg.sh` support a bundled runtime
payload. Point them at a prebuilt runtime tree and a prewarmed Hugging Face
cache:

```bash
export DICTATOR_BUNDLED_RUNTIME_DIR="/absolute/path/to/runtime"
export DICTATOR_BUNDLED_MODEL_DIR="/absolute/path/to/hf-home"
export DICTATOR_BUNDLED_RUNTIME_VERSION="gigaam-mlx 0.1.x"
export DICTATOR_BUNDLED_MODEL_VERSION="GigaAM v3 e2e RNNT"
./script/package_dmg.sh
```

Optional metadata:

```bash
export DICTATOR_BUNDLED_RUNTIME_SOURCE="https://github.com/aystream/gigaam-mlx"
export DICTATOR_BUNDLED_RUNTIME_LICENSE="MIT"
export DICTATOR_BUNDLED_MODEL_SOURCE="https://huggingface.co/aystream/GigaAM-v3-e2e-rnnt-mlx"
export DICTATOR_BUNDLED_MODEL_LICENSE="MIT"
```

When these variables are set the package embeds
`Contents/Resources/GigaAMPayload`, writes a manifest with deterministic
fingerprints, and the app installs the payload into
`~/Library/Application Support/Dictator/BundledAssets` from Settings without
requiring `uv`, `brew`, or a separate `.command` helper.

## Package app zip

```bash
./script/package_app.sh
```

Writes `dist/Dictator.app` and `dist/Dictator.zip`. The script:

1. Runs `swift build -c release`.
2. Generates a fresh `assets/AppIcon.icns` if it doesn't already exist.
3. Assembles the bundle, embeds the icon, sets `CFBundleIconFile=AppIcon`.
4. Re-ad-hoc signs the bundle.

## Package DMG for sharing

```bash
./script/package_dmg.sh
```

The DMG contains the app, a `/Applications` shortcut, and Russian first-run
notes. The app prepares its local speech runtime from Settings. If a bundled
payload is present it installs from the DMG; otherwise it performs an
app-managed download on the target Mac.

## Diagnostics

Stream the app's logs in another terminal:

```bash
log stream --info --style compact --predicate 'subsystem == "app.dictator.local"'
```

Categories: `Audio`, `Dictation`, `Insertion`, `Packaging`, `Transcription`.

Useful breadcrumbs:

- `Insertion target captured (focused|frontmost-app fallback) pid=... role=...`
- `Caret bounds (range|element) ax=... screen=...`
- `GigaAM command starting runtime=... timeout=120`
- `GigaAM command finished runtime=... elapsed=...`
- `GigaAM command timed out runtime=... seconds=120`
- `Pasteboard restored items=...`

## Integration test (3-minute audio)

`Tests/DictatorCoreTests/DictatorCoreTests.swift` includes an end-to-end
integration check that loads a WAV file, runs it through the real
`TranscriptionService` → `GigaAMRuntime` → `gigaam-mlx` chain, and asserts
the returned transcript is non-empty. It is gated on the
`DICTATOR_TEST_WAV` env var so it does not run by default.

```bash
DICTATOR_TEST_WAV=/path/to/test_3min.wav swift test --filter integrationThreeMinuteWavTranscribesEndToEnd
```

On the reference machine a 180-second Russian recording is transcribed end-to-end
in ~25–30 seconds wall clock (about 6× realtime).

## Known limitations

- Builds for the local architecture only (currently `arm64`).
- Universal Intel + Apple Silicon packaging still needs a working Xcode
  `xcbuild` setup or a separate Intel build machine.
- The default DMG is a small network bootstrap: the app downloads `uv`,
  `gigaam-mlx`, Python dependencies, and the model cache on the target Mac.
- Fully offline/self-contained delivery requires a bundled runtime payload at
  packaging time.
- Only `GigaAM v3 e2e RNNT` is exposed in Settings. The data model retains
  Whisper enum cases for future expansion, but the runtime path is Russian
  only — the Language picker was removed in this release.
- The app is ad-hoc signed for local testing, not notarized for public
  distribution. On first launch from `/Applications` Gatekeeper may block it
  — Control-click → Open, or remove the quarantine attribute:
  ```bash
  xattr -dr com.apple.quarantine /Applications/Dictator.app
  ```
- Replacing the app re-signs the binary, which can invalidate the cached
  Accessibility permission — toggle Dictator off and on in System Settings →
  Privacy & Security → Accessibility if dictation suddenly stops working.
